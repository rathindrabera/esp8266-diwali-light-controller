Subhavali Smart Diwali Light Controller

ESP8266 + 4-Channel Relay + 20 Vertical LED String Curtain (12V DC)

🎛️ Open Live Controller (Login Required)

📦 1. What You Need

NodeMCU ESP8266Wi-Fi Microcontroller brain running the web server & mDNS.
4-Channel 5V RelayOptocoupler isolated module switching 12V DC / 220V AC up to 10A/ch.
20 LED String LightsDivided into 4 groups of 5 strings each for animated patterns.
5V & 12V Power Supplies5V powers NodeMCU & Relay coils; 12V powers the LED strings.

🔌 2. Pinout & Wiring Table

Wire the low-voltage 5V control side between the ESP8266 and the 4-Channel Relay module first, then wire the 12V DC light strings:

🪜 3. Step-by-Step Setup Guide

  • Step 1Hang the 20 Vertical Strings (Interleaved Layout): Hang all 20 strings vertically along your balcony. Connect every 4th string in parallel: Bundle 1 = #1, #5, #9, #13, #17; Bundle 2 = #2, #6, #10, #14, #18; Bundle 3 = #3, #7, #11, #15, #19; Bundle 4 = #4, #8, #12, #16, #20.
  • Step 2Open the Web Dashboard: Connect your phone to the same Wi-Fi network and visit http://diwali.local. Anyone can view this Setup Guide at http://diwali.local/guide without logging in!
  • Step 3Control Modes & Wireless OTA Updates: Tap Control Dashboard and log in (default: admin / diwali2026) to preview patterns on the live 20-string visualizer, change Wi-Fi/security credentials at /settings, or upload firmware updates wirelessly at /update.
